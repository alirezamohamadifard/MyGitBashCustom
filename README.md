# ترمینال فارسی Git Bash

یک محیط دسکتاپ فارسی و مدرن برای کار با Git Bash در ویندوز.

## امکانات

- اجرای دستورات Git و Bash
- پشتیبانی از چند ترمینال مستقل
- توقف فرایندهای در حال اجرا با Ctrl+C
- رنگ‌بندی نحوی
- پیشنهاد هوشمند دستورات
- تاریخچه و آمار استفاده
- گزارش فعالیت و لاگ
- تم‌ها و تنظیمات ظاهری
- شناسایی و نصب Git for Windows

## نیازمندی‌ها

### نسخه آمادهٔ اجرا

- Windows 10 یا Windows 11 نسخه 64 بیتی
- Git for Windows؛ اگر نصب نباشد، برنامه می‌تواند با اجازهٔ کاربر آن را نصب کند
- اتصال اینترنت فقط برای دانلود خودکار Git for Windows

نسخه Self-contained به نصب جداگانهٔ .NET نیاز ندارد.

### اجرای سورس پروژه

- .NET 10 SDK
- Visual Studio 2022 یا جدیدتر با Desktop development with .NET
- Git for Windows

## نصب و استفاده

1. وارد بخش Releases شوید.
2. آخرین نسخه را دانلود کنید.
3. فایل ZIP را Extract کنید.
4. فایل `MyGitBashCustom.exe` را اجرا کنید.
5. اگر Git Bash نصب نیست، مراحل نصب پیشنهادی برنامه را دنبال کنید.

## میانبرها

| میانبر | عملکرد |
|---|---|
| `Enter` | اجرای دستور |
| `Ctrl+C` | توقف فرایند در حال اجرا |
| `Ctrl+Shift+C` | کپی |
| `Ctrl+Shift+V` | چسباندن |
| `Ctrl+L` | پاک‌کردن خروجی |
| `Ctrl+T` | تب جدید |
| `Ctrl+W` | بستن تب |
| `Ctrl+Tab` | جابه‌جایی بین تب‌ها |
